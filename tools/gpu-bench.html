GPU Hertzmann — validation & benchmark

Serve the repo root and open /tools/gpu-bench.html. Validates every GPU pass against its CPU equivalent, then benchmarks the full render.

The GPU path is not bit-identical to the CPU path and cannot be — float rounding differs by driver. What matters is that each pass agrees to within float tolerance, and that the final image is visually equivalent to the batched CPU reference (not the default CPU path, which grows strokes against a live canvas).
